# Carpeta `tool/`

Aquí se guardan los scripts de automatización (DevOps) escritos en Dart.
Se ejecutan con el mismo SDK que ya trae Flutter, en Windows, Linux o macOS:

```bash
dart run tool/<script>.dart
```
